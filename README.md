# Kniffel Terminal Edition 🎲

Eine moderne, blitzschnelle Terminal-Implementierung des Spieleklassikers Kniffel (Yahtzee), geschrieben in Java. Spielbar direkt in der Kommandozeile mit bis zu 4 Spielern, coolen ANSI-Animationen und JLine für flüssigen Tastatur-Input ohne ständiges "Enter" drücken.

## ✨ Features

- **1 bis 4 Spieler** im lokalen Multiplayer.
- **Kein Flackern:** Optimiertes Konsolen-Rendering.
- **Würfel-Animationen** und interaktive Menüs.
- **Lokales Highscore-System** (wird in `data/highscores.txt` gespeichert).
- **Native Terminal-Steuerung** (Pfeiltasten, direkte Tastatureingaben) dank `JLine`.

## 🚀 Installation & Start

### Voraussetzungen

- Java (JDK) 17 oder höher installiert.

### Variante 1: Über JAR ausführen

1. Lade dir die neueste Version unter [Releases](link-zu-deinen-releases) herunter.
2. Öffne dein Terminal und starte das Spiel:
   ```bash
   java -jar KniffelTerminalEdition.jar
   ```
